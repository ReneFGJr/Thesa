Glossário do Thesa

Conceito

Um conceito é uma ideia, noção ou representação mental que expressa o significado de algo.
Ele é abstrato e independente da linguagem.
Na organização do conhecimento, o conceito é a base que dá sentido aos termos usados para descrevê-lo.
É por meio dos conceitos que se estruturam as relações entre informações em sistemas como tesauros, ontologias e classificações.

Termo

Um termo é uma palavra ou expressão que representa um conceito específico em um determinado contexto.
Os termos são usados para nomear e descrever conceitos, facilitando a comunicação e a compreensão entre pessoas que compartilham o mesmo domínio de conhecimento.
Os termos podem variar de acordo com o idioma, a cultura e o contexto em que são utilizados.
Em sistemas de organização do conhecimento, como tesauros e ontologias, os termos são associados a conceitos para garantir que a informação seja acessível e compreensível.

Exportação pela API

Use GET /api/export/:id/:formato para baixar um tesauro inteiro ou um conceito em um dos formatos abaixo.

Formato Endpoint Content-Type Arquivo
{{ format.label }} /api/export/:id/{{ format.path }} {{ format.mime }} {{ format.extension }}

Qual ID usar

Para exportar toda a base, informe o ID do tesauro. Por exemplo, /api/export/6/xml exporta o tesauro 6.

Para exportar apenas um conceito, informe o ID do conceito e acrescente ?scope=concept. Por exemplo, /api/export/366/xml?scope=concept. Esse parâmetro é necessário quando um mesmo número identifica tanto um conceito quanto um tesauro. Sem scope, o ID do tesauro tem prioridade.

Acesso a tesauros não públicos

Envie a APIKEY de um proprietário ou colaborador em ?apikey=SUA_APIKEY ou no cabeçalho X-API-Key. Para exportar um conceito privado, combine os parâmetros: ?scope=concept&apikey=SUA_APIKEY. Tesauros públicos dispensam a chave. Evite compartilhar links com APIKEY, pois URLs podem aparecer no histórico e em logs.

Exemplos

curl -L "{{ exportApiUrl }}/export/6/turtle" -o thesa-6.ttl
curl -L "{{ exportApiUrl }}/export/366/json?scope=concept" -o concept-366.jsonld
curl -L -H "X-API-Key: SUA_APIKEY" "{{ exportApiUrl }}/export/ID/txt" -o thesa-ID.txt

A API retorna 200 no download, 403 quando não há autorização e 404 para um ID inexistente.

Exemplos de Uso

curl -X GET https://api.meusistema.com/users \
  -H "Authorization: Bearer seu_token_aqui"

Tratamento de Erros

Erros seguem o formato padrão HTTP com mensagens descritivas.
